## About project
Laravel shop

## Used technologies
- MySQL
- Node
- PHP, Laravel

## Installation
- git clone https://github.com/mikhalkevich/mathlab
- cd mathlab
- composer install
- npm i
- создать базу данных
- создать файл .env, в нём подкючиться к базе данных
- php artisan migrate 
- php artisan serve
- npm run dev
- После чего сайт будет доступен по маршруту http://localhost:8000
